# Epigenetic Age Calculator — Garma & Quintela-Fandiño (2024)

A Python application for estimating epigenetic age from DNA methylation **beta values (β-values)** using the **published coefficients** of Garma and Quintela-Fandiño (2024). The project supports Illumina HumanMethylation450K, MethylationEPIC v1, and MethylationEPIC v2 probe identifiers and can process one or multiple samples.

The application implements two prediction modes:

- **General model:** directly estimates age using the published general clock (Supplementary Table S5).
- **Combined model (default):** runs the general model first, then chooses the published young (S6), middle-aged (S7), or older (S8) model based on that initial prediction.

The project **does not train a new clock** or generate its own scientific coefficients. It uses the original model coefficients and the published CpG mean beta values for optional missing-value imputation. It is intended for education and research, **not for clinical diagnosis**. Matching published coefficients is not, by itself, proof of external predictive validation.

## Data and scientific methodology

### Published clock and reference coefficients

The clock is based on Garma and Quintela-Fandiño (2024). Its four published models are distributed in **Additional file 5, Tables S5–S8**. The original Excel workbook is stored in `suplementos_originais/S5_a_S8_coeficientes.xlsx`; its converted, ready-to-load version is `dados_referencia/coeficientes_originais_S5_S8.csv`. The coefficients are used as published: no model retraining is performed.

For each model, the predicted age is obtained from an intercept, linear CpG terms, and squared CpG terms:

```text
predicted_age = intercept + sum(linear_coefficient * beta)
                          + sum(quadratic_coefficient * beta^2)
```

The `order` column of the original coefficient tables distinguishes the intercept (`0`), linear terms (`1`), and quadratic terms (`2`). For the **combined** mode, the general model's preliminary prediction selects the second model:

| General-model estimate | Final model |
| --- | --- |
| 36 years or younger | Young (S6) |
| Older than 36 and younger than 59 | Middle-aged (S7) |
| 59 years or older | Older (S8) |

**Additional file 2, Table S2**, supplied as `suplementos_originais/S2_medias_beta.xlsx`, provides the published mean beta values used for optional imputation of missing CpGs. Its converted CSV is `dados_referencia/medias_originais_S2.csv`.

For EPIC v2, probe identifiers such as `cg00000029_TC21` are mapped to the base CpG ID (`cg00000029`) used by the model. When multiple valid measurements correspond to the same CpG within a sample, this implementation takes their **arithmetic mean**. This is an implementation choice and should be assessed for the intended analysis pipeline. Reported coverage counts **measured** required CpGs, not imputed ones.

### Public methylation dataset

For the practical example and evaluation, the project uses the public NCBI Gene Expression Omnibus (GEO) dataset **[GSE246337 — DNA methylation profiling of the Biomarkers of Aging Consortium Cohort](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE246337)**:

- **Organism / tissue:** human blood.
- **Platform:** Illumina Infinium MethylationEPIC v2.0.
- **Dataset:** 500 samples with processed DNA methylation beta values.
- **Source file:** [`GSE246337_betas.csv.gz`](https://ftp.ncbi.nlm.nih.gov/geo/series/GSE246nnn/GSE246337/suppl/GSE246337%5Fbetas%2Ecsv%2Egz).
- **Sample ages:** obtained from the GEO sample metadata and kept separately from the methylation matrix.

`extrair_gse246337.py` selects the following five publicly identified samples for a small reproducible demonstration:

| Sample ID | GEO sample accession | Chronological age (years) |
| --- | --- | ---: |
| BoA462 | [GSM7867425](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM7867425) | 18.44 |
| BoA45 | [GSM7867008](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM7867008) | 26.96 |
| BoA339 | [GSM7867302](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM7867302) | 41.46 |
| BoA11 | [GSM7866974](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM7866974) | 57.14 |

The extractor matches each subject to the technical Illumina column name in the large beta matrix, then keeps only probes relevant to the four clock models. It **does not** change the original beta values. These five sample IDs and ages are also recorded in `idades_cronologicas_5_pessoas.csv`.

The GEO data and the Garma model supplements are **separate resources from different studies**: the former provide example methylation measurements and known ages; the latter provide the prediction model and its reference means.

## How to run

Run commands from the project directory (the folder that contains `app.py`, `cli.py`, and `requirements.txt`). The examples below work from Windows Command Prompt with the `python` command; replace `python` with `python3` or `py` if that is how Python is installed on your computer.

### 1. Install dependencies (required for the calculator)

```bash
python --version
python -m pip install -r requirements.txt
```

A virtual environment is optional but recommended. If you use one, activate it before installing the dependencies.

### 2. Option A — Run the graphical interface (Streamlit)

```bash
python -m streamlit run app.py
```

Alternatively, if the `streamlit` executable is available:

```bash
streamlit run app.py
```

Open the local URL displayed in the terminal (usually `http://localhost:8501`). In the interface:

1. Choose **combined** (default) or **general** mode.
2. Choose whether to impute missing CpGs using the supplied S2 reference means (enabled by default).
3. Upload a beta-value CSV, TSV, TXT, or XLSX file containing one or multiple samples.
4. Select the input layout: CpGs in rows, samples in rows, or long format.
5. Run the calculation and download the summary and missing-probe CSV reports.

The published coefficients and means are **already included**. Uploading replacement model tables is optional; do not use the artificial test coefficients for scientific predictions.

### 3. Option B — Run the command-line interface (CLI)

Run the combined clock on the five extracted GEO samples:

```bash
python cli.py --betas amostras_epicv2_5_pessoas.csv --mode combined --out resultados_5_pessoas
```

Run only the general model:

```bash
python cli.py --betas amostras_epicv2_5_pessoas.csv --mode general --out resultado_geral
```

Read the **original Excel supplements** instead of their converted CSV versions:

```bash
python cli.py --betas amostras_epicv2_5_pessoas.csv --mode combined --weights suplementos_originais/S5_a_S8_coeficientes.xlsx --means suplementos_originais/S2_medias_beta.xlsx --out resultado_excel
```

Disable missing-value imputation:

```bash
python cli.py --betas amostras_epicv2_5_pessoas.csv --sem-imputacao --out resultado_sem_imputacao
```

Without imputation, a prediction is **not produced** when a required CpG is missing. By default, the CLI assumes CpGs are in rows and samples in columns (`--layout cpg_rows`). Other supported layouts are `--layout samples_rows` and `--layout long`.

For an output prefix such as `resultados_5_pessoas`, the CLI writes:

- `resultados_5_pessoas_resumo.csv`: age prediction, preliminary age, selected model, probe counts, measured coverage, and status, per sample.
- `resultados_5_pessoas_ausentes.csv`: missing CpG IDs and whether each one was imputed, per sample.

The report field names are currently in **Portuguese**, following the application's implementation. The chronological ages are held separately in `idades_cronologicas_5_pessoas.csv`: the CLI **does not automatically calculate age-estimation errors**. To assess accuracy, join the files by sample ID and calculate `absolute_error = abs(epigenetic_age - chronological_age)` for each sample with a valid prediction.

### 4. Prepare the five-sample subset from the original GSE246337 download

If `amostras_epicv2_5_pessoas.csv` and `idades_cronologicas_5_pessoas.csv` already exist, **skip this step**.

Place `GSE246337_betas.csv.gz` in the project directory, then run:

```bash
python extrair_gse246337.py
```

The script reads the compressed ~3.5 GB dataset **directly**, line by line; it does not require decompressing the entire matrix into memory. It reads the CpG requirements from `dados_referencia/coeficientes_originais_S5_S8.csv` and creates the two smaller CSV files listed above.

You can also customize the paths:

```bash
python extrair_gse246337.py --entrada GSE246337_betas.csv.gz --pesos dados_referencia/coeficientes_originais_S5_S8.csv --saida .
```

After extraction, run either **Option A** (upload the subset in Streamlit) or **Option B** (use the CLI command above). The original `.csv.gz` is **not a direct input format** of `app.py` / `cli.py`; use the extractor first.

### 5. Supported input formats

The default layout is **one CpG probe per row, one sample per column**:

```csv
CpG,sample_A,sample_B
cg00000029_TC21,0.72,0.45
cg00000109_TC21,0.93,0.92
```

Alternatively, the loader accepts **samples in rows** or **long format** (`probe,sample,beta`); select the matching layout in Streamlit or with `--layout` on the CLI. Beta values must be numeric in the range **0 to 1**. Missing values are handled according to the imputation setting. Multiple EPIC v2 probe measurements mapping to one CpG are averaged as noted above.

The included `exemplo_betavalues.csv` is **synthetic** and intended to demonstrate the file layout, not to evaluate the model's biological accuracy.

### 6. Run the automated tests

```bash
python -m unittest discover -s tests -v
```

The tests check parser behavior, model selection, quadratic terms, multiple-sample processing, missing values, duplicate probe handling, and consistency of the Excel supplementary model data with the converted CSVs. Passing these checks verifies aspects of the implementation; **it does not establish clinical validity or guarantee agreement with published individual-level predictions**.

## Outputs and interpretation

For each processed sample, the calculator reports the estimated epigenetic age (in years), the preliminary general-model estimate, the final model selected, the number of probe rows received, the number of unique CpGs received, the number of usable measured CpGs, the number of required/used CpGs, the list of missing or imputed CpGs, and **measured coverage**.

**Measured coverage (%) = 100 × (required CpGs with measured beta values) / (required CpGs for the applied prediction path).** Imputed CpGs are not counted as measured. In combined mode, the applied path contains the general model and the selected age-specific model.

A coverage warning below 95% is an **implementation-specific precaution**, **not** a validated threshold from the original article. Results depend on quality control, normalization, probe availability, and imputation. A difference between chronological and predicted age should not be interpreted as a medical diagnosis.
